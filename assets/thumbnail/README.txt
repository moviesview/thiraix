Add one poster image per movie in this folder.

Use the SAME movie filename/title as the video in Google Drive, but with an image extension.
Examples:
  Drive video: Leo.mp4          -> assets/thumbnail/Leo.jpg
  Drive video: Captain America.mkv -> assets/thumbnail/Captain America.png

Supported poster extensions: .jpg, .jpeg, .png, .webp
The site checks this local folder first. If no matching local poster is found, it falls back to the API/Google Drive thumbnail.
